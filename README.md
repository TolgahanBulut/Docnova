# Docnova 


## Kurulum

### 1. Projeyi Klonlayın
```bash
git clone https://github.com/TolgahanBulut/Docnova.git
cd docnova
```

### 2. Bağımlılıkları Yükleyin
```bash
npm install
```

### 3. Çalıştırın
```bash
npm start
```

Uygulama http://localhost:3000 adresinde açılacak.
